## Rev 8 / 8.1 in one screen
- **Hub stack, top → bottom:** optional layers (display…, on the 2×10 expansion header; the JST-SH expansion board stays too) / **core layer** = one base board, **94 × 77 mm** (front edge y −30), one ESQ joint tall: **MDBT50Q-U1MV2** (u.FL; single source), the whole power path, TCA9548A, button connectors, stacking headers; u.FL → **Yageo ANTX100P011B24003 PCB antenna inside the rear wall**, **blanked knock-out for the Yageo ANTX100ETHAB24553 whip** behind it (both Raytac-approved with CE); **front wall: NKK UB power (latching, green) / reset (red) / boot (black)** / **connector layer**, swappable, chooses the medium (wired: carrier + 3 socket boards = hub-population comms boards on `J_SLOT`) / **battery modules 1–3, 4×AA NiMH, passive** **or a Qi2 board** instead (never charges cells) / base with 4 × 3M Bumpon SJ5012 feet.
- **Key modules are dumb:** key board with a TI **MSPM0G3505SPTR** (LQFP-48 PT) module controller serving one I2C register map, IS31FL3733, **TPS7A0233PDBVR** LDO; module-side comms board (USB-C, BAT54C CC→`INT`, `J_COMM`); slot VBUS TVS **TVS0500DRV** on both comms populations. Link = plain USB 2.0 C-to-C cable: VBUS = switched LED rail, D± = SDA/SCL (400 kHz, auto 100 kHz fallback per slot), CC = `INT` (220 kΩ pull-ups from `SLOT_EN`). A USB 2.0 cable has no spare conductor, so `J_COMM`/`J_SLOT` spares never cross it. A slot is on while its module answers (~200 ms window, ~100 ms re-probe every ~2 s awake, none asleep).
- **Battery module (rev 8.1, passive):** MPD **BC4AAPC** (57.2 × 61.3 × 15.5 mm, <50 mΩ, at (−5, −15), cells along x) + Bourns **MF-MSMF125/16X** PTC (16 V, 1.25 A hold, 0.14 Ω max) + the pogo seam parts + the chain line shift (own pack → its pins' `PACK_A`; `PACK_A`/`PACK_B` from its discs → pins' `PACK_B`/`PACK_C`; `PACK_C` from below ends, so a 4th module is unconnected). A lifted module's pins carry its raw pack (PTC-limited).
- **Hub power (rev 8.1), one `SYS` rail:** per pack input SMF4L9.0CA TVS + **LM74610-Q1** + **CSD17313Q2** (zero Iq, reverse to −45 V, OR; **1 µF** pump cap) → `VBAT` → **CSD25402Q3A** P-FET "Qb" (gate pull-up **1 MΩ** to `VBAT`) → `SYS`, on only when the power button is latched AND **TPS3840PL40** (`VDD` from the pack inputs via **BAT54C + BAT54**, then **10 kΩ, 1 µF**: off at 4.0 V ±1.5 % on that node, ~4.16 V at the hub input, on ~200 mV higher) AND no USB (N1–N4 = 2 × **DMN63D8LDW**: N1 from the UVLO output via the power button, **4.7 MΩ** pull-down, ~1 µA through the gold contact; N2 = NOT-VBUS in series, **1 MΩ** pull-up to `VBAT`; N3 grounds N2's gate on USB; N4 turns on the USB switch through a **2.2 MΩ / 22 nF delay with a BAT54 bypass**). USB: **TPS3840PL43** on `VBUS_IN` (absent <4.3 V, present >~4.5 V, powered by `VBUS_IN`, output also to a GPIO) turns on a second **CSD25402Q3A** "Qu" (source `SYS`, drain `VBUS_IN`, body diode VBUS→SYS, gate pull-up **10 kΩ** to `SYS`; **100 kΩ** bleeder on `VBUS_IN`). **`SYS` 100 µF.** The LM74610 runs ~45–60 ms on its body diode (~0.77 V drop) each time a pack takes over, then 25 ms every ~1.2 s: never sense the UVLO after it. ### Key board specifics
- MSPM0G3505 **48-pin PT numbering** (SLASEX6C Table 6-2, second number column; the first is the 64-pin package): link SDA/SCL = **PA0/PA1, pins 1/2** (default BSL I2C, 5 V-tolerant open-drain, BSL address 0x48); `BSL_invoke` = **PA18, pin 33**; SWD PA19/PA20 = 34/35; NRST 4, VDD 6, VSS 7, VCORE 48 (capacitor only).

## Gotchas
- `tools/kicad-check.sh` **always exits 1**: every board without an outline has one "no board outline" DRC violation. The rev 7 core PCB carries 303 DRC items (8 known `hole_clearance`, 15 unconnected, silk); it is being replaced. Judge by ERC (14 sheets, 0 violations on 2026-09-29) and `interconnect: … 0 errors`.
- `gen_kicad.py` rewrites every library footprint without UUIDs and `kicad-check.sh` normalises them with fresh UUIDs, so untouched footprints show UUID-only diffs. Restore them: `for f in $(git diff --name-only hardware/lib/keyboard.pretty); do [ -z "$(git diff $f | grep '^[-+]' | grep -v '^[-+][-+]' | grep -v uuid)" ] && git checkout -- $f; done`.
- `symbol()` in `gen_kicad.py` spaces top/bottom pin names 5.08 mm apart (fixed 2026-09-29). Keep symbol widths a multiple of 5.08 mm so pin ends stay on the 2.54 mm grid.
- TI "(8.2)"-style dimensions on land-pattern examples are pad centre-to-centre.
- kicad-sch-api 0.5.6: symbols unrotated, always writes `(in_bom yes)` (`schlib.post_process` fixes). Derived (`extends`) symbols → ERC mismatch: use `Device:D` / a `keyboard:` copy (the stock `TCA9548APWR` is not derived; stock KiCad 10.0.6 has no MSPM0G350x or TPS7A02). ERC ignores variants: keep variant-exclusive power outputs apart with a jumper.
- **Read a part's whole datasheet before recommending it**: the LM74720-Q1 was approved and then replaced once its internal boost turned up in the pin table (2026-09-30); the 24AA02/24LC02B looks like a fit until the pin note says A0–A2 are not connected (2026-10-01).
- **Check a module's approved-antenna list before choosing an antenna**: Raytac's -U list ruled out every RP-SMA option (2026-10-01).
- **FreeCAD MCP recipe**: run the model with `execute_python`: `p='<repo>/mech/hub/build_hub.py'; g={'__file__': p}; exec(open(p).read(), g); _result_=g['_result_']` (pass `__file__` so the script finds the repo). **`get_screenshot` fails** (a bug in the tool). Take images (call `v.setAnimationEnabled(False)` first, or the view is still mid-animation) with `FreeCADGui.getDocument('hub').ActiveView.saveImage('<repo>/build/mech/hub/x.png', 1400, 1100, 'White')` after `viewFront()`/`viewTop()`/`viewIsometric()` + `SendMsgToActiveView("ViewFit")`, then Read the PNG. Interference check: every pair's `a.Shape.common(b.Shape).Volume` over objects with volume, **skipping `App::DocumentObjectGroup`** (a group's Shape is all its children); clearances with `a.Shape.distToShape(b.Shape)[0]`. Labels: `<layer>_shell` is the printed section, `<layer>_board` the PCB. Hiding objects for a view: re-run the model afterwards to restore visibility.
