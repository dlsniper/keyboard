## Working rules
- **PCB design work, the overall layout and the keyboard body (case, hub CAD) are done by the main session, not
  delegated** (user, 2026-11-13: no tokens spent on fixing a cheaper model's mistakes); FreeCAD and KiCad (CLI and
  MCPs) may be used freely for it. Delegate only work where a mistake is cheap to catch.
- One clean session per milestone, split at a task boundary if it grows. End every session by updating this file and
  committing. Read only what the task needs; bulk work goes to cheaper models (table in the roadmap);
  subagents may nest up to five levels, results are verified by whoever delegated.
